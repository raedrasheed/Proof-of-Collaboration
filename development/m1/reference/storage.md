# تخزين ملفات الويب

**البدائل**
- S1 (SSTORE): نحو 640 gas/B.
- S2 (calldata مع بصمة): لا يحقق المطلب، لأن البايتات خارج الحالة.
- S3 (bytecode لعقود قطع): نحو 220 gas/B.
- S4 (طبقة أصلية بإيجار): تتيح الحذف، ولا تعمل على anvil.

المختار (D10): S3 للتجربة، وS4 شرط لشبكة عامة دائمة.

**أين البيانات وكيف تُسترجع**
- كود عقود القطع داخل حالة كل عقدة كاملة.
- الاسترجاع بـeth_getCode، وهي طريقة خفيفة: الرد ≤ 2·24576+64 بايتًا، أي نحو 48 KiB سداسيًا. يستدعيها عامل الإضافة عبر ChunkFetcher لا عبر جسر الموقع، فلا تستهلك دلو الجسر ولا عدّاد تعليقه. لكنها تمر بـRecvGuard بحد 68 KiB لكل رد ضمن CONTENT_POOL، وبـChunkCache لجلسة الموقع (D98، D99).
- eth_getProof ضمن K_eff، وهي ثقيلة، ومحظورة على الموقع (D95).

**المصنع (D27)**
store(bytes data)، حيث 1 ≤ |data| ≤ 24575:
- salt = keccak256(data).
- initcode = 61 LL LL 80 60 0a 5f 39 5f f3 ‖ 00 ‖ data، حيث LLLL = be16(1+|data|).
- runtime = 0x00‖data، والعنوان بـCREATE2، والعملية idempotent.
- العميل يتحقق من code[0]=0x00 ومن الطول.

**Manifest**
RLP([1, entryIndex, files])، حيث file = [path, mimeId u8, size u32, contentHash keccak256, chunks [[addr20, len u32]…]].
- 1 ≤ len ≤ 24575، وΣlen = size ≤ 1 MiB.
- entry من نوع html، والملفات مرتبة بايتيًا بصرامة.
- المسار: ('/' seg)+، حيث seg = [A-Za-z0-9._~-]+، وليس '.' أو '..'، وطوله ≤ 256، وحساس لحالة الأحرف.
- MIME: 1 html، و2 css، و3 js، و4 json، و5 png، و6 jpeg، و7 webp، و8 svg، و9 woff2، و10 text.
- التطبيع (يستعمله العارض وsite_navigate، D96): query وfragment خارج البحث. '%' و'//' و'.' و'..' تعطي 404. المسار الفارغ أو '/' = entry، و'/x/' = '/x/index.html'.

**عقد Website**
- الخانات: 0 owner، و1 pendingOwner، و2 versionCount|currentVersion، و3 Version{manifestHash، manifestLen|status|publishedBlock، قطع manifest}، و4 publishers، و5 publisherCount.
- الحالات: 0 مسودة، و1 منشور، و2 ملغى.
- PUBLISHER: createVersion، وpublish، وsetCurrent.
- OWNER: الناشرون (≤ 16)، وrevoke لغير الإصدار الحالي، ونقل الملكية بخطوتين.
- حدود العقد: manifest ≤ 64 KiB، والإصدارات ≤ 1024.
- حدود العميل: الموقع ≤ 4 MiB، و≤ 256 ملفًا، وجلب متوازٍ ≤ 8 اتصالات خفيفة من العقدة المحلية، ومهلة 10s. ردود −32021 تُعاد بعد retryAfterMs.

**متجهات الرفض (T16)**
مسار مكرر أو غير مرتب أو '.' أو غير ASCII، وmime مجهول، وentry غير html، وعدم تطابق size أو len أو hash، ومصنع آخر، وRLP غير قانوني، وبايت زائد، وcode[0] ≠ 0.

**الرسوم والزمن (فرضيات)**
القطعة نحو 5.4M gas، أي قطعة لكل كتلة. موقع 1 MiB يحتاج نحو 47 كتلة، ونحو 0.25 عملة عند 1 gwei.

**الإصدارات والحذف**
- التحديث إصدار جديد، والاسترجاع بـsetCurrent، وrevoke يمنع العرض الافتراضي.
- لا حذف للبايتات حتى النهاية (EIP-6780)، وكل الإصدارات تبقى في التاريخ.

**التخزين المحلي للموقع (ليس على الشبكة، D34، D96)**
حالة localStorage للموقع محلية في المتصفح فقط، وليست جزءًا من حالة الشبكة. تفاصيلها ومحاسبة حصتها في browser. حفظها في سجلات نسخ غير قابلة للاستبدال، وتعافيها عند زوال العامل، محددان في D103.

**RetentionStore**
- الأحجام: الحساب 120 B، والخانة 150 B، وعقدة trie = 32+4+RLP، والإيصال المضغوط ≤ 54 B، والسجل = 36+len.
- الفهارس: txHash ≤ 64 B، وheight 40 B، وSettlementIndex ≤ 242 B لكل كتلة.
- المتجهات:
  - RC1 = c7 01 82 52 08 80 80 80.
  - LG1 = d7 94 ‹20› c0 80، بمخزن 60 B.
  - LG2: 546 سجلًا تنجح، و547 تتوقف.
  - LG3 = 193 B.
- GenesisSpec وalloc يُحفظان مع اللقطة.
- السجلات بمفتاح (height, blockHash) للسلسلة القانونية.
- LogCursor يمسح تصاعديًا على لقطة واحدة دون تحميل النطاق، ويرمّز كل سجل مطابق في مخزن الحجز (D88). ذاكرة المسح لكل كتلة ≤ 4 MiB مفترضة (RG15).
- لقطة redb تُحرر عند نهاية الحساب (≤ 5s). ذاكرة redb المؤقتة مشتركة وثابتة.
- SettlementIndex (D78): غير إجماعي بمفتاح (j, blockHash)، يُعرض للفرع القانوني، ويُعاد بناؤه عند reorg.

**trie**
الحي ≤ 447 B لكل مدخل، والتاريخي ≤ 1.6 GiB، وP(d) = 568d+186+32(d+1).

**الاحتفاظ**
الكتل والإيصالات والسجلات والكود والفهارس حتى النهاية، مع trie حي، وK_eff ≤ 32، وفروق لـ2048 كتلة.

**الجرد (أسوأ حالة)**
عدد الكتل ≤ H_END=129600، وهو حد فعلي بـE1. المجموع نحو 19.65 GiB منطقيًا ونحو 29.5 GiB على القرص.

التوزيع بالـGiB:
- الكتل: الرؤوس 0.37، والأدلة 0.99، والمعاملات 8.00.
- المخرجات: الكود 1.03، والسجلات 1.00، والإيصالات 0.50، والفهارس 0.63.
- الحالة: الحسابات 0.11، والخانات 0.56، والنظام 0.02.
- trie والتاريخ: trie الحي 2.14، والتاريخي 1.60، والفروق 1.92، والجانبية 0.76.

الإغلاق (≤ Z_close=160) داخل H_END. في end/full يُشتق الجرد بـH_END=700 (CL-END).

**المدة والنسخ**
- الاحتفاظ حتى ts_F+30 يومًا، ثم لقطة موقعة.
- N_rep ≥ 3 على جهازين ماديين على الأقل. أقل من نسختين حيتين بعدّ ReplicaMonitor في pocol_getRetention (D119) يعرض «الاحتفاظ غير مستوفى» (T25).
- الرؤوس المرفوضة لا تُخزن.

**منع الإغراق**
- إغراق الكتابة: gas، والسقوف، والحدود المشتقة، والمجمع، والصنبور، والبند 10أ.
- إغراق القراءة: D88 وD90 وD92 وD94.
- إغراق الموقع عبر الجسر: D95 وD96 وD97 (دلو المعدل الصحيح، وعدّاد التعليق، والحصة المحلية المحسوبة حرفيًا).

**التمويل**
رسوم نشر لمرة واحدة. الجلب على المشغلين ضمن حدود D88.
