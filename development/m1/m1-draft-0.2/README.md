## What the evidence does and does not show

**Shows:**
- the fixtures are internally consistent with the written rules and their precedence;
- each isolation claim holds against the reference model;
- the draft 0.1 vectors agree across two independent Keccak/RLP implementations (pycryptodome/pyrlp for draft 0.1, this standard-library tooling for draft 0.2).

**Does not show:**
- correctness of any implementation;
- EVM behaviour or gas;
- browser behaviour;
- pocold `eth_getProof` support;
- agreement with the M0 K1–K3 libraries.

The reference model was written by the same author as the fixtures. Codex review of `tools/m1model.py` and `tools/m1paths.py` against the prose is part of the next review.
