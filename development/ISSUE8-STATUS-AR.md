# اتصال GitHub بالمنسق المحلي

الاتصال المحلي مفعّل بعد اختبار فعلي: وصلت رسالة المسألة #8 إلى المنسق القائم، أكد Codex استلامها، وعاد رد الحالة إلى GitHub. تكرار الطلب وإعادة تشغيل عملية المحول لم ينشئا طلباً أو رداً إضافياً. نجح ٧٧ اختباراً للمحول و٨٦ للمنسق و١١ فحص HTTP مستقل، وفحوص انقطاع الخدمة واستعادة النسخة الاحتياطية.

يعمل محول نقل واحد كل ٦٠ ثانية؛ لا حلقة وكيل جديدة ولا تشغيل مؤلف تلقائي. حُفظ رابط الواجهة والمنفذ والرموز الخاصة والخيط والحالة والتحكم بالإيقاف. تظهر الرسائل والردود والمراجعات الفعلية في الواجهة العربية.

حظر LP3 محفوظ دون إعادة محاولة أو تجاوز. يكفي تعليق من حساب المالك على المسألة #8 يبدأ بـ /pocol status ومعرّف جديد، أو /pocol guidance ومعرّف جديد ثم نص التوجيه. النقل والاستلام لا يمنحان موافقة شخصية ولا يثبتان تنفيذ العمل؛ الحالات مرتبطة بالسجل الفعلي. الأدلة في ISSUE8-ACCEPTANCE.json وissue8/e2e/ROUNDTRIP-EVIDENCE.json.
