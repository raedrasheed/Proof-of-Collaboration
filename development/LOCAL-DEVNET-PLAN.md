Authority: latest user authorizes successive local experimental milestones, sequential Claude authorship and independent Codex review/testing. No production, real funds, purchases, destructive migration, automatic merges or fabricated owner approvals. Gap assessment: LP1 verifies immutable synthetic fixture headers and readonly RPC only. Its roots are opaque and profile non-bootable. It cannot execute transactions, validate H-full, recover durable state, choose a live canonical chain, mine/produce new blocks, synchronize peers or serve contracts/websites. M1 acceptance is specification acceptance, not implementation acceptance. In particular H-full item17 requires EVM execution, and M5 peer-network code requires prior VA-spec review (D115). EVM therefore precedes claims of fully validated block production/network consensus, even though web contracts come later.
